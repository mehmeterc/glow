# Glow — Motion Playground

Open-source, browser-based rooster animation playground.

## Run

Open `index.html` in a modern browser or deploy it to any static hosting provider. No dependencies or build step are required.

## Features

- 10-second 16:9 Canvas animation
- Rooster entrance, size, sunrise speed and crow timing controls
- Playback and WebM export (browser support required)
- Local command parser for basic Turkish and English commands

## Important limitations

The ChatGPT sign-in button is a placeholder. There is no configured OpenAI OAuth client or GPT-powered chat backend. A ChatGPT Plus subscription does not automatically provide OpenAI API credentials. Never embed an API key in browser JavaScript.

This is a reconstructed implementation of the Glow prototype, not an exact export of the deployed Vercel source. The existing Vercel deployment remains unchanged.
